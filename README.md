# StudyLah

A personal study tracker for logging sessions, reflecting on what you learned, and seeing your weekly progress.

## Use it

Open `index.html` in a modern browser. Add a subject, the time you spent studying, and an optional note. Your sessions and summary are saved in your browser on this device; no account or server is needed.

## Develop

The app uses browser-native HTML, CSS, and JavaScript. To run the focused data tests, use Node.js 18 or newer:

```sh
npm test
```
